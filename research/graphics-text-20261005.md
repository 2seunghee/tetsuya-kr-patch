# 그래픽 텍스트 조사 (2026-10-05, 2차)

방법: emucap 실행 중 VRAM·팔레트·OAM·I/O 레지스터를 덤프(`tools/emucap_nav.py`의 `dump:` 단계)하고 `tools/gba_render.py`로 레이어를 복원한 뒤,
화면의 텍스트 타일 바이트를 ROM에서 역검색했다. 모든 대상이 **비압축 4bpp OBJ 타일**로 확인됐다(BIOS LZ77 블록 5개에는 없음).

## G-04/G-05 화자 이름표 — 해결

- 저장: 포인터 테이블 `0x081fa1f8`(39항목) → 항목 = `[u8 w][u8 h][w*h 타일×32B]`. 이름표는 6×2(48×16) 항목 30개(인덱스 6~35):
  哲也, キツネ目, カツラ, シラガ, 房州, トビ, 双子・兄, 双子・弟, 徳三, エビス, ダンチ, 印南, 信, リサ, アメリカかぶれ, 根津・夫, 根津・妻, 周坊, ユウ, 中, 鷹, 客A, 客B, 客C, ママ, 店主, 店長, マスター, ダンチの父, ？？？.
  나머지 항목(5×1 ×5, 2×2 ×1, 4×6 ×3)은 커서·필드 스프라이트다.
- 소비: 대사 창 좌하단 OBJ(48×16, 팔레트 4; 2D 매핑으로 타일 322~327/354~359에 적재). 대국 시작 화면의 플레이어 명판도 같은 자원으로 추정(미확인).
- 픽셀 규약: 1=검은 윤곽, 15=흰 채움, 2~14=질감 배경. `tools/plategen.py`가 원본 배경을 행 단위로 복원해 글자를 지우고 Galmuri(11→9→7 중 맞는 크기)로
  한글을 그린다. 교체는 **같은 크기 제자리 쓰기**(포인터 불변). 표기는 `config/plates.json`(대사에 등장하지 않는 별명 キツネ目·カツラ·シラガ·エビス·周坊·鷹은
  에이전트 임의 표기 → 사람 확인 필요).

## G-03 타이틀 메뉴 — 해결

- OBJ 타일 시트 `0x0862923c`(1024타일, 코드 리터럴 `0x3ad0`), 팔레트 12/13. 항목 3개 = 80×32(10×4 타일, 2D 매핑): フリー対局(타일 660), シナリオ対局(788), オプション(916).
  타일 532 블록은 선택 강조 테두리. 「PUSH START BUTTON」(타일 20~)은 영문이라 유지. 로고 「哲也」「甦る伝説」「勝負師伝説」·저작권 표기는 브랜딩으로 유지(DEC-005).
- 규약: 1=테두리/윤곽, 행별 그라데이션 배경(열 2의 값을 행 배경으로 복원), 15=글자. `tools/spritetext.py` + `config/sprite_texts.json`(프리 대국 / 시나리오대국 / 옵션, Galmuri11-Bold).
- 「はじめから」 슬롯 메뉴(G-03b)와 타이틀 자막 「言葉ひとつに たくさんの意味」(G-02)는 해당 순간의 덤프가 아직 없다(자막은 대사 bank에 없음).

## G-06 대국 화면 라벨 — 해결

- 덤프 경로: `tap`의 내부 `after_frames`를 쓰는 `tapa:` 단계가 장면 전환을 견딘다(별도 `step`은 전환 직후 `cleanup_failed`). 96회 입력까지 덤프 성공(`work/emucap/match3`).
- HUD 시트 `0x08376bbc`(4bpp OBJ, 팔레트 2): 「運」(타일 17, 2×2), 「力」(타일 81), 숫자, 패 그래픽. → 운/힘(Galmuri11, 채움 15·윤곽 1).
- 대국 라벨 시트 `0x08442ffc`(4bpp OBJ, 팔레트 5; 코드 리터럴 참조 없음 → 인덱스 계산으로 접근): 32×32 「局東南一二三四」(행 4~8), 「本場」(타일 25), 「点」(84),
  「二連荘~八連荘」(264~288), 소형 「東南西北」(328~334), 「続行」(344), 「セーブ」(408). → 국/동/남/1~4(Galmuri11 2배), 본장, 점, N연장, 동남서북, 계속, 세이브.
  시트 하단(행 14 이후)은 다른 형식의 데이터라 손대지 않는다.
- 숫자·패 그래픽은 그대로 둔다. 「東一局」은 32×32 글자 3개를 조합해 그리므로 글자 교체만으로 「동1국」이 된다.
- 슬롯 시트 `0x0842b5dc`(팔레트 6, 코드 리터럴 `0x1e2c`): 「はじめから」(타일 1, 10×3), 「つづきから」(11), 「シナリオ選択」(138), 「対局中...」(452, 8×2) → 처음부터/이어하기/시나리오 선택/대국 중...
  (흰 글자·부드러운 음영 → Galmuri11-Bold 채움 15, 윤곽 2).

## 빌드 반영

`tools/build.py`가 이름표 30건(386B 고정 길이)과 스프라이트 타일 교체(메뉴·슬롯·HUD·대국 라벨, `config/sprite_texts.json`)를 Expected Write로 등록한다.

## G-02 타이틀 순환 자막 — 범위 제외

- 저장: 스프라이트 테이블 `0x081fa0c8`(77항목, 같은 `[w][h][타일]` 형식)의 32×2 항목 13개(인덱스 23~35, `0x1bbef2`~`0x1c1f0a`), 팔레트 10, 값 1 단색.
- 내용은 주제가 가사 13행(영문 구절 포함)으로 확인됨. 저작권이 있는 가사이므로 번역·재작성 대상에서 제외하고 원본을 유지한다(DEC-005에 반영).
