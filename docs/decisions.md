## DEC-001 글리프 공급원 (상태: 에이전트 제안, 사람 승인 대기)

- 범위: 대사 엔진(12px 피치, 16px 셀) 전체 한글 텍스트.
- 질문: 어떤 한글 글꼴을 쓸 것인가.
- 선택지: (a) **Galmuri11** (SIL OFL 1.1, 10–11px 폭 × 11px 높이, 피치 12px에 정확히 맞음, 반각·기호 포함) — 추천.
  (b) Galmuri14/NeoDunggeunmo 계열 14–16px 폭 — 12px 피치에서 겹침, 피치 변경(코드 수정, 줄당 13칸)이 필요해 비용·위험 큼.
  (c) 시스템 글꼴(굴림 12px 비트맵) — 재배포 권리 불명확.
- 현재: (a)로 PoC 진행(`research/poc-20261005.md`). 시각 품질 판단은 사람이 스크린샷으로 확인 후 승인.
- 재검토: 가독성 불만, 글리프 누락, 라이선스 조건 변화.

## DEC-002 ROM 확장 (상태: 에이전트 제안, 사람 승인 대기)

- 범위: 제품 산출물 형식.
- 질문: 8 MiB 원본을 16 MiB로 확장해 새 데이터를 모두 확장 영역에 둘 것인가, 원본 내 빈 공간(약 330 KB)에 맞출 것인가.
- 추천: 확장(16 MiB). 원본 영역 변경이 포인터·리터럴 사이트로 한정되어 검증이 단순하고, 글리프·텍스트 예산 걱정이 없다.
  에뮬레이터·플래시카트에서 일반적으로 동작하지만 실기 검증은 별도 과제.
- 재검토: 실기 호환 문제 보고.

- 적용: 1차 범위 = 대사 엔진 전체(2,564 메시지, 40,799자). 타이틀 로고·메뉴 그래픽·마작 UI는 조사 후 별도 결정.

  릴리스 후보가 아니다(개발 정책 빌드).

## DEC-005 그래픽 텍스트 범위 (상태: 에이전트 제안, 사람 승인 대기)

- 범위: 대사 엔진 밖 텍스트(`research/graphics-text-20261005.md`).
- 제안: 화자 이름표 30종·타이틀 메뉴 3항목은 한글화(구현 완료, 개발 빌드 반영). 타이틀 로고·「勝負師伝説」·「PUSH START BUTTON」·저작권 표기는 원본 유지(브랜딩·영문).
  슬롯 메뉴(はじめから 등)·타이틀 자막·대국 화면 라벨(運 등)은 위치 확인 후 한글화.
- 별명 표기(여우눈·가발·백발·에비스·슈보·타카)는 대사에 등장하지 않아 임의 표기이므로 사람 확정 필요.
